# 03 — 按钮绑定菜单 / 接口固定顶层

**What to build:** 收紧按钮与接口两类权限点的父级语义：按钮只能绑定到某个菜单（父级下拉只列菜单节点，编辑时可换绑到另一个菜单）；接口固定为顶层、不提供父级控件；后端对全部类型做「父级类型一致性」校验（菜单→菜单/顶层、按钮→菜单、接口→顶层），非法组合被拒绝，从数据层面保证层级结构类型干净。

**Blocked by:** 02 — 菜单父级选择（调整层级）

**Status:** ready-for-agent

- [ ] 按钮类型的父级是「绑定菜单」下拉：只列 `type=menu` 节点（不含按钮/接口），编辑时可将按钮换绑到另一个菜单
- [ ] 接口类型不显示父级控件，固定为顶层（`parent_id=0`）
- [ ] 后端类型一致性校验：菜单→菜单/顶层、按钮→菜单、接口→顶层；非法组合（菜单挂按钮/接口、按钮挂按钮/接口、接口挂任何父级）被拒绝并返回业务错误、不落库
- [ ] 单测覆盖（维护 seam）：各类型非法父级组合 → 拒绝；合法组合（按钮换绑菜单、接口顶层、菜单挂菜单/顶层）→ 放行

**Tests:** 纯单元测试扩展权限点维护 seam —— 参数化覆盖非法类型组合与合法组合的放行/拒绝。
