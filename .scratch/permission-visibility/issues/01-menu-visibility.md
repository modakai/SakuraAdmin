# 01 — 菜单「显示/隐藏」全链路

**What to build:** 系统负责人在权限管理页可以决定某个菜单是否在侧边栏显示：把菜单设为「隐藏」后，它不再出现在前端侧边栏（隐藏目录则整棵子树一并隐藏），但用户仍可通过 URL 直达、权限码仍有效、仍可分配给角色；管理树里隐藏菜单带「已隐藏」标记，随时可改回显示。隐藏与禁用是两个独立维度，互不影响。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 系统负责人可在权限管理表单中把某个菜单设为「隐藏」或改回「显示」，保存后生效并在管理树中带「已隐藏」标记
- [ ] 隐藏的菜单不出现在侧边栏；隐藏目录时整棵子树一并隐藏；可见目录下全部子节点被隐藏时目录也不渲染为空菜单
- [ ] 隐藏菜单仍可 URL 直达、权限码仍有效、仍可分配给角色（隐藏 ≠ 禁用，`status` 语义不变）
- [ ] 新增菜单默认「显示」；编辑时正确回显 `visible`、`status`、`remark`（修复现状编辑时 `status` 被硬编码、`remark` 被清空的缺陷）
- [ ] 「显示/隐藏」控件仅在类型为「菜单」时出现
- [ ] MySQL 与 PostgreSQL 双库迁移同步新增 `visible` 列，历史数据回填为「显示」
- [ ] 后端树测试：管理端树包含隐藏菜单且 `visible` 透传到节点；登录菜单树构建不受 `visible` 影响（隐藏节点仍在树中）

**Tests:** 纯单元测试扩展树查询 seam —— 构造含隐藏节点的数据集，断言管理端树包含它且节点带 `visible`；断言登录树仍包含它。
