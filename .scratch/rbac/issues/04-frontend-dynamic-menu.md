# 04 — 前端动态菜单/路由（宽重构）

**What to build:** 前端登录后根据后端下发的权限点树动态生成侧边栏菜单与路由：无权限的菜单不显示，无权限的 URL 被路由守卫拦截，按钮按 `v-permission` 指令控制显示。原静态导航注册表退出"导航唯一事实来源"职责，降级为组件注册表。登录态下导航与权限管理页配置一致。

**Blocked by:** 03 — 登录聚合返回与权限点树

**Status:** ready-for-agent

- [ ] 侧边栏由后端返回的菜单树渲染，层级与排序与配置一致
- [ ] 路由动态注册（addRoute），无权限路径被守卫拦截并提示
- [ ] `v-permission` 指令控制按钮显示
- [ ] 组件标识 → import() 映射表就绪，动态菜单组件能正确加载
- [ ] 原静态导航注册表不再驱动菜单，降级为组件注册表
- [ ] 超管看到全部菜单，普通用户只看到有权限的菜单
