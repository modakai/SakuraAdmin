# naive-vue-app 导航注册表设计

`naive-vue-app` 使用前端静态导航注册表作为后台页面导航结构的唯一事实来源。注册表位于 `src/app/router/navigation.ts`，同时生成 Vue Router 的后台子路由和 Naive UI 的左侧菜单，避免路由路径、标题、图标和菜单层级在多个文件里重复维护。

## 已确认边界

- `导航注册表` 是唯一事实来源。
- `菜单分组` 只组织侧边栏，不进入 Vue Router。
- `导航页面` 才生成真实路由。
- 后台业务页使用懒加载组件，页面文件位于 `src/features/*/pages`。
- `@` 指向 `src`，用于减少深层相对路径。
- `/profile` 是可访问后台页面，但不展示在左侧菜单，只保留顶部用户入口。
- 本轮不接后端动态菜单，只预留后续扩展空间。

## 设计约束

注册表可以保存标题、路径、组件、图标和菜单可见性。菜单组件只负责把注册表适配为 `MenuOption`，不能再维护第二份页面清单。路由文件只负责创建路由实例和守卫，不能再手写后台页面 children。

新增后台页面时，先创建对应 `features/<feature>/pages/<Feature>Page.vue`，再把页面注册到导航注册表。不要恢复 `src/views` 目录。
